可数集：能排成一列的集合

ℵ₀

定义

集合A是可数的，如果存在双射 A → ℕ

即可以排列为：a₁, a₂, a₃, ...

经典例子

  • ℕ（自然数）可数 ✓
  • ℤ（整数）可数 ✓
  • ℚ（有理数）可数 ✓
  • ℝ（实数）不可数 ✗

关键性质

可数个可数集的并是可数的

5

康托尔对角线论证

证明 [0,1] 不可数

x₁ = 0.a₁₁ a₁₂ a₁₃ a₁₄ ...
x₂ = 0. a₂₁ a₂₂ a₂₃ a₂₄ ...
x₃ = 0. a₃₁ a₃₂ a₃₃ a₃₄ ...
x₄ = 0. a₄₁ a₄₂ a₄₃ a₄₄ ...
⋮
y = 0.b₁b₂b₃... 其中 bn ≠ ann
𝔠

结论

y ∈ [0,1] 但与所有 xn 都不同

⇒ [0,1] 不可数

基数层级

ℵ₀ < 𝔠 = 2^ℵ₀

有理数在实数中"微不足道"

集合列的上下极限

上极限集 limsup An

⋂n=1∞ ⋃k=n∞ Ak

= 属于无穷多个 An 的元素

无论从哪一步开始，后面总能找到包含x的集合

下极限集 liminf An

⋃n=1∞ ⋂k=n∞ Ak

= 从某项起永远属于 An 的元素

最多不属于有限个集合

liminf An ⊆ limsup An （总是成立）

若两者相等 ⇒ lim An 存在

开集：没有边界的集合

定义

G是开集，如果对每个 x∈G，存在 ε>0 使得

B(x, ε) ⊂ G

（ε-邻域完全在G内）

例子

  • (a, b) 是开集 ✓
  • [a, b] 不是开集 ✗
  • ℝ 是开集 ✓
  • ∅ 是开集 ✓
8

闭集：包含所有聚点

定义

F是闭集，如果

Fᶜ 是开集

等价于：F包含它的所有极限点

例子

  • [a, b] 是闭集 ✓
  • (a, b) 不是闭集 ✗
  • {1/n : n∈ℕ} ∪ {0} 是闭集 ✓
  • ℤ 是闭集 ✓

聚点 vs 孤立点

聚点：每个邻域都包含A中异于x的点

孤立点：存在邻域只包含x自己

闭包

Ā = A ∪ A'

A' = A的所有聚点

Ā 是包含A的最小闭集

开集与闭集的对偶性

开集性质 闭集性质
任意多个开集的并是开集 任意多个闭集的交是闭集
有限个开集的交是开集 有限个闭集的并是闭集
∅ 和 ℝ 是开集 ∅ 和 ℝ 是闭集

紧集：有限覆盖性质

开覆盖

集合K的开覆盖是一族开集 {Gα}，使得

K ⊆ ⋃α Gα

紧集定义

K是紧集，如果K的每一个开覆盖都有有限子覆盖

直觉

紧集是"有限集的推广"——虽然可能有无穷多个点，但在覆盖的意义上表现得像有限集

11

Heine-Borel 定理

K 是紧集 ⟺ K 是有界闭集

✓ 紧集

[a, b] 有界且闭

⇒ 紧

✗ 非紧

[0, ∞) 闭但无界

⇒ 非紧

✗ 非紧

(0, 1) 有界但不闭

⇒ 非紧

⚠ 注意

此定理仅对 ℝⁿ 成立！

一般空间中有界闭 ≠ 紧

完备性：柯西列必收敛

柯西列

数列 {xn} 是柯西列，如果

∀ε>0, ∃N: m,n>N ⇒ |xm-xn|<ε

完备性

度量空间中的每个柯西列都收敛

ℝ vs ℚ

  • ℝ 是完备的 ✓
  • ℚ 不完备 ✗

例：1, 1.4, 1.41, 1.414, ... 是ℚ中的柯西列，但极限 √2 ∉ ℚ

关键

完备性是ℝ区别于ℚ的根本

14

完备性的等价表述

柯西列收敛（柯西完备性）
单调有界数列收敛（单调收敛定理）
确界原理：非空有上界的集合有上确界
闭区间套定理：嵌套闭区间的交集非空
Bolzano-Weierstrass：有界数列有收敛子列
Heine-Borel：有界闭集是紧的

这些命题在ℝ中彼此等价，构成实分析的根基

波莱尔集包含什么？

单点集

{a} 是 Gδ 集

{a} = ⋂(a-1/n, a+1/n)

有理数集

ℚ 是 Fσ 集（可数并）

ℚ = ⋃q∈ℚ {q}

无理数集

ℝ\ℚ 是 Gδ 集

ℝ\ℚ = ℚᶜ

康托尔集

闭集，因此是波莱尔集

测度为0但不可数

重要事实

分析中遇到的"几乎所有"集合都是波莱尔集

拓扑空间：最抽象的推广

定义

拓扑空间 (X, 𝓣) 由集合X和开集族𝓣组成，满足：

T1

∅, X ∈ 𝓣

T2

G₁,G₂∈𝓣
⇒ G₁∩G₂∈𝓣

T3

{Gα}⊂𝓣
⇒ ⋃Gα∈𝓣

这三条公理抽象了 ℝⁿ 中开集的核心性质，使得"连续性"、"收敛性"等概念可以在没有距离的空间中定义
