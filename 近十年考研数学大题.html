2018 · 数学一 · 第18题
构造辅助函数 + 罗尔定理
证明存在 ξ 使得变限积分等式成立 —— 考研证明题经典范式
题 1

题目 · 2018 数学一 · 第18题

已知条件

设 f(x) 在 [a, b] 上连续

函数 f(x) 在闭区间 [a, b] 上连续，满足连续函数的一切性质（介值定理、最值定理等均可使用）。
求证目标

存在性证明

∃ ξ ∈ (a, b)，使得
∫aξ f(t) dt = (b − ξ) f(ξ)
即：找到一个点 ξ，使得 f 从 a 到 ξ 的积分恰好等于矩形 (b−ξ)×f(ξ) 的面积。
此类「证明存在 ξ」的题目，核心套路是构造辅助函数，使其导数为零时恰好给出目标等式。
题 1

知识点储备

知识点 A

罗尔定理

若 G(x) 在 [a,b] 连续，在 (a,b) 可导，且 G(a) = G(b)，则 ∃ ξ ∈ (a,b) 使得
G′(ξ) = 0
知识点 B

变限积分求导

若 F(x) = ∫ax f(t) dt，则
F′(x) = f(x)
（f 连续时成立，牛顿-莱布尼茨的核心）
知识点 C

构造函数策略

目标：G′(ξ) = 0 恰好给出待证等式。

逆向思维：将等式移项 → 看作某函数的导数 → 反积分得到 G(x)。
三大核心定理（零点/罗尔/拉格朗日）是考研证明题的根基，几乎每年必考。构造辅助函数是「灵魂一步」。
题 1

推导过程

1
构造辅助函数
由目标等式 ∫aξf(t)dt = (b−ξ)f(ξ)，构造：
G(x) = (b − x) ∫ax f(t) dt
2
对 G(x) 求导
乘法法则：G′ = (b−x)′·∫ + (b−x)·(∫)′
G′(x) = −∫axf(t)dt + (b−x)f(x)
3
验证端点值
G(a) = (b−a)·0 = 0
G(b) = 0·∫abf(t)dt = 0
第四步 · 应用罗尔定理

条件逐一验证

  • G(x) 在 [a,b] 连续 ✓
  • G(x) 在 (a,b) 可导 ✓
  • G(a) = G(b) = 0 ✓
由罗尔定理 →
∃ ξ ∈ (a,b)，G′(ξ) = 0
↓ 即 ↓
∫aξ f(t)dt = (b−ξ)f(ξ)
∎

欧拉常数与级数求和
裂项消元 + 泰勒展开判敛 —— 级数求和的精妙操作
题 2

题目 · 级数敛散性与求和

题目

判断级数敛散性，若收敛求和

S = ∑n=1∞ (1/n − ln((n+1)/n))

分析思路

通项 an = 1/n − ln(1+1/n)，需要先判断通项衰减速度，再利用部分和结构求极限。
关键预备知识

欧拉-马歇罗尼常数 γ

γ = limn→∞(∑k=1n 1/k − ln n) ≈ 0.5772
题 2

推导过程

1
泰勒展开分析通项
令 u=1/n，展开 ln(1+u)=u − u²/2 + u³/3 − ⋯
an = 1/n − (1/n − 1/(2n²) + O(1/n³))
= 1/(2n²) + O(1/n³)
与 ∑1/n² 比较（p=2 > 1），级数 收敛。
2
裂项求部分和
对数项可望远镜消去：
∑n=1N ln((n+1)/n) = ln(N+1)
3
写出部分和表达式
SN = ∑n=1N 1/n − ln(N+1)
↓ 变形 ↓
= (∑n=1N 1/n − ln N) − ln((N+1)/N)
4
取极限
∑1/k − ln N → γ
ln((N+1)/N) → 0
S = γ
γ ≈ 0.5772（欧拉常数）

曲面积分遇到奇点 —— 经典的「挖去小球」处理技巧
题 3

题目 · 曲面积分

计算
I = ∯Σ (x dy dz + y dz dx + z dx dy) / (x²+y²+z²)3/2
其中 Σ 为封闭曲面（球面），取外侧方向，且原点在曲面内部。

核心难点

被积函数在原点 r = 0 处无定义 → 不能直接用高斯公式。需要特殊处理。
⚠ 关键事实
令 P=x/r³, Q=y/r³, R=z/r³（r=√(x²+y²+z²)），
在 r ≠ 0 处：∂P/∂x + ∂Q/∂y + ∂R/∂z = 0
题 3

推导 · 挖球法

1
散度为零的证明
∂(x/r³)/∂x = (r²−3x²)/r⁵，三项求和：(3r²−3r²)/r⁵ = 0
2
挖去小球 Σε
在原点挖半径 ε 的小球，夹层区域 Ω 内散度 = 0。由高斯公式：
∯Σ − ∯Σε = ∭Ω 0 dV = 0
∴ I = ∯Σε(外侧)（转化为小球面上计算！）
3
小球面上直接计算
在 Σε 上 r = ε，法向 n = (x,y,z)/ε
I = ∯ (x²+y²+z²)/(ε³·ε) dS
↓
= 1/ε² · ∯ dS = 1/ε² · 4πε²
I = 4π
与外层曲面形状无关！

2016 · 数学一 · 第21题
Gronwall 不等式思想
f(0)=0 + |f′| ≤ k|f| → 证明 f ≡ 0 —— 微分方程唯一性的核心
题 4

题目 · 恒等于零的证明

已知

条件设定

  • f(x) 在 [0, +∞) 上可导
  • f(0) = 0
  • ∃ k > 0 使得 |f′(x)| ≤ k|f(x)| 对 ∀x ≥ 0 成立
求证
f(x) ≡ 0
直觉：f(0)=0，若 f 想「长起来」，其导数受 f 本身限制 → 被「锁死」在零。这就是 Gronwall 不等式的精髓。
题 4

推导 · 三步证明

1
积分放大
|f(x)| = |∫0x f′(t)dt|
≤ ∫0x |f′(t)|dt
≤ k ∫0x |f(t)|dt
令 g(x) = ∫0x|f(t)|dt
则 g′(x) = |f(x)| ≤ kg(x)
2
构造 h(x)
h(x) = g(x) · e−kx
求导：
h′ = g′e−kx − kg·e−kx
= e−kx(g′−kg)
≤ 0（因为 g′ ≤ kg）
h(x) 单调递减
3
锁定为零
h(0) = g(0) = 0

h(x) ≥ 0（因为 g ≥ 0）

h(x) 单调递减
递减 + 非负 + 初值为 0
h(x) ≡ 0
⟹ g(x) ≡ 0 ⟹ f(x) ≡ 0
∎

题 5

反常积分 · 参数微分法

I = ∫0∞ ln x / (1+x²)² dx
1
引入参数 I(s)

题 14

递推数列 · 三问连击

递推关系
x₁ > 0, xn+1 = ln(1 + xn)
第 (1) 问
证明 limn→∞ xn = 0
第 (2) 问
证明 limn→∞ xn+1/xn = 1
第 (3) 问 · 最难
证明 limn→∞ n · xn = 2
第 (3) 问是重中之重，需要用到 Stolz 定理（离散版的洛必达法则）。
题 14

第 (1)(2) 问 · 单调有界 + 基本极限

第 (1) 问

证明 lim xn = 0

1
xn > 0（归纳法）
x₁>0, xn>0 → xn+1=ln(1+xn)>0 ✓
2
xn+1 < xn（单调递减）
设 g(x)=x−ln(1+x), g(0)=0, g′(x)=x/(1+x)>0
→ g(x)>0 即 ln(1+x) < x ✓
3
极限方程
设 lim xn=a, 则 a=ln(1+a) → a=0 ✓
第 (2) 问

证明 lim xn+1/xn = 1

xn+1/xn = ln(1+xn)/xn
↓
由第 (1) 问 xn→0，利用基本极限
↓
limu→0 ln(1+u)/u = 1
∴ 极限 = 1 ∎
题 14

第 (3) 问 · Stolz 定理 —— 全卷最难

Stolz 定理
若 bn 严格递增趋于 +∞，且 lim (an+1−an)/(bn+1−bn) = L，则 lim an/bn = L
1
计算关键差分
令 an = 1/xn（→∞），bn = n
1/xn+1 − 1/xn = (xn − ln(1+xn)) / (xn·ln(1+xn))
2
泰勒展开（xn→0）
分子 = xn²/2 − xn³/3 + ⋯
分母 = xn² − xn³/2 + ⋯
3
求极限
比值 → (½ · xn²) / (xn²) = 1/2
4
应用 Stolz 定理
lim (an+1−an) / (bn+1−bn) = (1/2) / 1 = 1/2
↓ Stolz ↓
lim an/bn = lim (1/xn)/n = 1/2
lim 1/(nxn) = 1/2
∴ lim n·xn = 2
∎
题 14

知识点 · Stolz 定理深度解读

定理陈述

Stolz-Cesàro 定理

∞/∞ 型：
设 {bn} 严格递增且 bn→+∞

若 lim (an+1−an)/(bn+1−bn) = L
则 lim an/bn = L
使用条件

何时想到 Stolz？

  • 求 lim (nxn) 型问题
  • 分母是 n（或 n 的简单函数）
  • 分子 1/xn 的差分容易计算
  • 相当于离散版洛必达法则
关键步骤

本题的核心操作

① 取倒数：将 nxn→? 转化为 (1/xn)/n→?

② 算差分：1/xn+1−1/xn

③ 泰勒展开：分子分母同除 xn²

④ 结论：差分极限 = 1/2
